One job. The thinnest layer.

Agentic AI is a loop, not a menu

If a workflow can do it, it is not an agent.

Understand → find → act → orchestrate

One job enters the loop. It leaves at the first layer that can finish it. Retrieval, a control loop, a tool protocol, and a peer are layers. Most jobs stop early.

How a job moves

One question, then only the layer it still needs. The loop continues when this layer cannot finish the work, and it has to be able to stop.

Where judgement stays

A person still chooses the layer, the stop, and what may write.

  1. Start at the thinnest layer that solves the job. Prompted chat, then a cited answer. Add a loop only when the work branches, retries, and has to be able to stop.
  2. RAG, MCP, and an agent answer different questions. Retrieval grounds facts. A protocol reaches a tool. An agent is the control loop. Rules are standing orders. A skill is a runbook you load when the task matches.
  3. A person still approves money, production, and irreversible writes. Name the tool allowlist, the step and spend caps, and what the loop does when approval does not come.

If you cannot name the stop, the allowlist, and who approves, you do not ship the loop. Facts that change weekly stay in retrieval, not in the weights.
